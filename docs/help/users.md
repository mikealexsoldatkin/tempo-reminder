# Users

This tab holds the two lists the app works from. **Managers** comes first, because tracked users
pick their recipients out of it — while it is empty those columns cannot be edited. A manager does
not have to be tracked themselves.

**Tracked users** is who gets checked: being in the list means "look for their time in Tempo, and
write to them if a working day is missing". Add them with **Add users**, or pull in a whole project
with **Add project members**. Everyone here gets a personal reminder, always.

Who else hears about a person is set by two independent columns — the **basic report** ("hasn't
logged time") and the **detailed report** (day by day, with issues). Fill either, both or neither.
Emails are how a person is found in Slack, so if Jira hides one, type it into the cell yourself.
